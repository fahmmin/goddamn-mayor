What holds it honest

Three constraints the code actually enforces.

No name, no write

The oracle asks ENS first

  • Only mayor.cityhall.eth may publish.
  • The name expires with the term.
  • Then the city stops reporting itself.

The chain is removable

One script tag

  • src/ never reaches the network.
  • Delete the bundle; the game is unchanged.
  • Play the whole thing with no wallet.

A dead RPC is staleness

Never a crash

  • The panel keeps its last known numbers.
  • The badge flips to stale on its own.
  • The simulation does not notice.
